## 目录结构

```text
rain.study/
├── README.md                     # 总入口
└── notes/
    ├── README.md                 # 所有学习笔记的目录
    ├── frontend/
    │   ├── README.md             # 前端专区
    │   └── html-css.md           # HTML / CSS 学习笔记
    └── algorithms/
        └── README.md             # 算法与数据结构专区
```

## 后续整理方式

- 每个主题放在自己的专区，专区 README 维护阅读入口。
- 一篇笔记使用一个一级标题，按知识点组织章节，代码块标明语言。
- 题解可以放在 `notes/algorithms/problems/`，练习代码可以放在对应主题的 `examples/`。
- 增加新主题时，在 `notes/` 下创建独立目录，并更新总目录。
